# 🚨 RescuePulse Med AI

Autonomous Multi-Agent Emergency Triage & Coordination System

---

## 🧠 Problem
Emergency departments face delays in identifying critical patients due to messy and unstructured input.

---

## 🚀 Solution
RescuePulse Med AI analyzes patient input, prioritizes severity, alerts doctors, and coordinates emergency resources like blood and hospital support in real time.

---

## 🔥 Features

- 🧠 Handles spelling mistakes & noisy input  
- ⚡ Real-time patient prioritization  
- 🚨 Doctor alert system  
- 🩸 Blood group & quantity detection  
- 🏥 Hospital coordination & tracking  
- 💬 ChatGPT-style UI  
- 📊 Explainable AI reasoning  

---

## 🏗 Architecture

- Perception Agent → cleans input  
- Triage Agent → detects severity  
- Decision Agent → diagnosis  
- Coordination Agent → alerts & resources  

---

## 🛠 Tech Stack

- Python  
- Streamlit  
- RapidFuzz  

---

## ▶️ Run

pip install streamlit rapidfuzz  
streamlit run app.py  

---

## 🎯 Impact

Reduces emergency response time and supports doctors in critical decision-making.

---

## ⚠️ Disclaimer

Doctor must confirm all decisions.
